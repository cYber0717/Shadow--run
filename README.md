# Shadow Run

A small SFML animation demo. It opens a window and lets you try a few character moves.

Right Arrow ....run
Space ....jump
Up Arrow ...climb
Down Arrow ...slide

The animations use sprite sheets from the `assets/characters` folder, so keep those files in place when you run it.

In the complete version of the game we would have a player having moves from assets folder moving through obstacles.There will be background and ground platform will also be shadow style.The user has to compelete it in 1 minute and avoid barriers to win the game.
